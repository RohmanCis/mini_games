## 📌 Deskripsi
Project ini berisi dua mini games Python yang *simple* tapi efektif buat melatih:
- logika conditional  
- fungsi modular  
- validasi input  
- penggunaan `random`  
- struktur folder yang rapi  
- version control dengan Git  

Cocok untuk latihan mandiri atau portfolio project pemula.
